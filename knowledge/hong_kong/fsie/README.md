# 香港 FSIE 候选知识包

这是第一个可校验的研究包骨架，不是税务意见，也不是已验证的规则库。

当前状态：

- 所有资料记录均为 `not_ingested` 或 `unverified`；
- 所有规则节点均为候选规则，必须经香港税务专家审核后才可激活；
- 测试案例全部为虚构案例，不得替换为客户资料；
- `content_sha256` 为空，表示原件尚未由受控资料管线抓取并哈希；
- 规则节点只定义输入、证据和停止状态，不输出免税/应税结论。

验证命令：

```bash
python3 scripts/validate_fsie_package.py
```

下一步应是受控抓取官方原件、计算哈希、按法律单元解析，并由专家逐条确认规则和证据要求。
