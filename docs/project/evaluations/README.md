## 现阶段已完成

Taxora品牌及中英文界面、邮箱注册登录和重置密码、邮件模板、账号隔离、流式回答和停止、Markdown与复制、历史对话重命名和归档、图标悬浮提示。

## 接下来按顺序处理

1. 检索后形成直接答案并关联依据，避免停留在“我将查阅”。
2. 定位参与豁免、案情汇总、无依据免税确认三题的报错，区分模型调用和输出校验问题。
3. 改善检索相关性和多法条覆盖，避免短碎片或只匹配第一条法条。
4. 核对税务概念、案例类型、地区范围和资料时效表述。
5. 完整走通案情收集、更正、事实确认、规则分析、待复核清单，再使用同一批问题复测。

建议分工：A跟踪用户体验和复测，Agent负责人处理回答链路与报错，检索/数据负责人处理召回和资料质量，税务专家确认法律解释。具体负责人由团队认领，以上问题尚未修复。

## 队友如何配置

先按根目录README安装依赖，将根目录`.env.example`复制为`.env`，按照[认证说明](../TAXORA_AUTH.md)配置。数据库连接凭据、模型API密钥和认证配置由项目负责人私下提供，不在Git中保存真实`.env`。修改代码时不要覆盖队友的个人环境配置。
