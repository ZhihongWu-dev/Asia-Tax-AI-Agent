## 6. 评测记录格式

每次执行记录：用例 ID、层次、代码 commit 或工作区摘要、policy_version、模型/provider 版本、夹具版本、前置状态、输入轮次、期望动作、实际动作、实际调用计数、事实 diff、业务状态/错误码、耗时、结论和失败原因。

真实模型集不少于 60 个多轮脚本：H01～H54 中涉及语言理解的行各覆盖原表达，再为未知/更正/混合请求/切换增加改写、否定、英语或混合语言样本。结构和事务行可以只用确定性输入；不能为了凑数重复同一脚本。

阻断发布的问题：错误事实写入、重复提交副作用、资料权限泄漏、无依据肯定结论、擅自确认/批准、未知转否定、等待用户时继续自答。任一出现即修复并重跑受影响用例组。工程层通过但真实模型集不达标时，保留测试环境、关闭生产动态规划。

目标：关键边界用例零违规；真实模型冻结集路由正确率至少 95%；记录而不虚构真实 C 的可用率和 P95 耗时。性能先检查重复模型解析、重试叠加、上下文过长和读取原文次数，再决定是否需要更多流式输出。
