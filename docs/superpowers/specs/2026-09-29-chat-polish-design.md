# Taxora 六项体验补齐

用户已授权按既定六项优先级完成，维持简约双语界面。认证恢复和重发入口已实现。

- 回答：react-markdown + remark-gfm，禁用原始 HTML 和远程图片，安全链接新窗口打开。复制按钮明确成功或失败。
- 阅读：接近底部才自动跟随；用户向上滚动保留位置，提供回到底部按钮。切换对话时定位最新内容。
- 对话：按更新时间分组；重命名、归档、恢复归档沿用服务端账号隔离、版本检查和幂等请求。不做永久删除。
- 流式：真实模型 SSE 经后端转发；JSON 回复只展示 reply 字段的增量，完整结构验证后才应用事实并保存。取消关闭模型连接，不提交部分事实。完整回复提交与取消发生竞态时，以服务器保存结果为准。
- 验证：隔离数据库测试账号权限、版本冲突、流式异常及取消；浏览器验证排版、复制、阅读位置、归档恢复和停止操作；构建后更新本地服务。

参考：remarkjs/react-markdown（MIT）、remarkjs/remark-gfm（MIT）的官方 README、安全说明及问题记录；DeepSeek Chat Completion SSE 协议；Starlette StreamingResponse 断连机制。保留依赖许可证，不复制外部产品设计。
